# Чистая речь

Сайт-одностраничник для онлайн-занятий с учителем-логопедом Анастасией. Первый шаг перед
будущей кроссплатформенной развивающей игровой платформой с логопедическими играми — отсюда
блок "скоро игры" на странице.

Дизайн-система (шрифты, цвета, тон общения) следует официальному брендбуку заказчика —
подробности и рабочий журнал изменений см. в [CLAUDE.md](CLAUDE.md).

Весь текстовый контент на сайте сейчас — плейсхолдеры (`[Плейсхолдер]`, `[Цена]`,
`[Имя родителя]` и т.д.), логотип и иллюстрации — актуальные, из брендбука v2
(`assets-source/brand-v2/`).

## Стек

React 19 + TypeScript + Vite + Tailwind CSS 4.

## Команды

```bash
pnpm install
pnpm dev       # http://localhost:5173
pnpm build     # прод-сборка в dist/
pnpm preview   # предпросмотр прод-сборки
pnpm lint      # oxlint
```

## Структура

```
src/
  components/   # секции лендинга (Header, Hero, About, Services, ...)
  assets/       # логотип и другие изображения
  App.tsx       # сборка секций по порядку
  index.css     # Tailwind + кастомная тема (шрифты, цвета)
```

Компоненты уже разделены по секциям, чтобы при переходе к полноценной платформе
(многостраничность, роутинг, игры) не пришлось переписывать вёрстку с нуля.
