# Чистая речь

Сайт-одностраничник для онлайн-занятий с логопедом Анастасией. Первый шаг перед будущей
кроссплатформенной развивающей игровой платформой с логопедическими играми — отсюда блок
"скоро игры" на странице. Стиль ориентирован на детскую аудиторию и намеренно повторяет
язык логопедических лендингов-конкурентов (logosha-online.ru): шрифты **Poppins** (заголовки)
+ **Nunito** (текст), мягкие скруглённые карточки, кнопки-«таблетки», sticky-шапка с тенью.

Весь контент на сайте сейчас — плейсхолдеры (`[Плейсхолдер]`, `[Цена]`, `[Имя родителя]` и т.д.),
логотип временный (`src/assets/logo.png`, фон снят скриптом `scripts/remove-logo-bg.py`
из `src/assets/logo-source.jpg`). Иллюстрации в Hero и блоке "скоро игры" —
`src/assets/banners/banner-1-zanyatie.svg` и `banner-2-popugay.svg`.

## Стек

React 19 + TypeScript + Vite + Tailwind CSS 4.

## Команды

```bash
pnpm install
pnpm dev       # http://localhost:5173
pnpm build     # прод-сборка в dist/
pnpm preview   # предпросмотр прод-сборки
pnpm lint      # oxlint
```

## Структура

```
src/
  components/   # секции лендинга (Header, Hero, About, Services, ...)
  assets/       # логотип и другие изображения
  App.tsx       # сборка секций по порядку
  index.css     # Tailwind + кастомная тема (шрифты, цвета)
```

Компоненты уже разделены по секциям, чтобы при переходе к полноценной платформе
(многостраничность, роутинг, игры) не пришлось переписывать вёрстку с нуля.
